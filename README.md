# Проект "Банковские операции"

## Описание

Проект "Банковские операции" — новый виджет, который показывает несколько последних успешных 
банковских операций клиента.

Проект включает в себя набор функций-генераторов для эффективной фильтрации банковских транзакций, извлечения их
описаний и генерации валидных номеров пластиковых карт по заданному диапазону. Использование итераторов позволяет
экономить оперативную память при работе с большими объемами данных.

## Функции и примеры использования

Все функции возвращают **итераторы (генераторы)**. 
Ниже приведены примеры того, как их можно импортировать и 
использовать в коде.

1. `filter_by_currency`
Фильтрует список транзакций по указанному коду валюты (например, `USD`, `RUB`).

**Пример кода:**
```
from src.generators import filter_by_currency  
# Скорректируйте путь импорта при необходимости

transactions = [
    {"id": 1, "operationAmount": {"currency": {"code": "USD"}}, "description": "Покупка"},
    {"id": 2, "operationAmount": {"currency": {"code": "RUB"}}, "description": "Перевод"},
    {"id": 3, "operationAmount": {"currency": {"code": "USD"}}, "description": "Кэшбэк"}
]

usd_transactions = filter_by_currency(transactions, "USD")

for tx in usd_transactions:
    print(tx)
# Выведет только транзакции с id 1 и id 3
```
2. `transaction_descriptions`
Принимает список транзакций и поочередно возвращает текстовое описание (`description`) для каждой операции.

**Пример кода:**
```
from src.generators import transaction_descriptions

transactions = [
    {"id": 1, "description": "Перевод организации"},
    {"id": 2, "description": "Открытие вклада"}
]

descriptions = transaction_descriptions(transactions)

for desc in descriptions:
    print(desc)
# Выведет:
# Перевод организации
# Открытие вклада
```
3. `card_number_generator`
Генератор, который выдает номера банковских карт в стандартном формате `XXXX XXXX XXXX XXXX` в заданном числовом диапазоне. Автоматически дополняет номера ведущими нулями до 16 знаков.

**Исключения (`ValueError`):**
* Если числа меньше `1`.
* Если длина числа превышает 16 цифр.
* Если `start_num` больше, чем `stop_num`.

**Пример кода:**
```
from src.generators import card_number_generator

# Генерация номеров от 1 до 3
cards = card_number_generator(1, 3)

for card in cards:
    print(card)
# Выведет:
# 0000 0000 0000 0001
# 0000 0000 0000 0002
# 0000 0000 0000 0003
```
