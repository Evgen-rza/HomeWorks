# Проект "Банковские операции"
## Описание
Проект "Банковские операции" - новый виджит, который 
показывает несколько последних успешных банковских операций клиента.
## Установка 
1. Клонируйте репозиторий:
```
git clone https://github.com/Evgen-rza/HomeWorks.git
```
2. Установите зависимости:
```
poetry install
```
## Использование
1. Запустите программу
```
python mail.py
```
2. Следуйте инструкциям далее
